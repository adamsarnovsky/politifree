# Third-party software and models

The MIT license covers the project-owned source. Python packages listed in `outputs/Politifree-Companion/requirements.txt`, transitive dependencies, downloaded model weights and browser runtimes retain their original licenses. No Python environment, browser runtime, model weights or third-party package source is included in this repository.

`model-manifest.json` and the companion's setup code identify the model sources and pinned assets. Before distributing bundled weights or third-party binaries, verify each upstream model card and package license and preserve required notices. This source release does not relicense those assets or assert that every downstream distribution has been legally reviewed.
