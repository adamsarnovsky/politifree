# Privacy

Normal filtering and companion inference run locally. Website requests still go to the sites you browse; media fetching may contact the original media host. Politifree does not send your feed to the community update server.

Reports are user-initiated. Choosing an item copies up to 1,000 characters and a decision reason into an editable local form. Public URLs are manually entered. No screenshots, audio, images, account identifiers or browsing history are automatically attached. Review the exact JSON and consent before exporting or opening a GitHub draft. GitHub receives the draft fields when that URL opens, even before you submit the issue. Submitted issues are public and subject to GitHub's privacy and retention policies. Redact private posts and personal information first.

Automatic filter checks contact `raw.githubusercontent.com` approximately every six hours while Chrome is running. GitHub receives ordinary connection metadata such as IP address. Requests omit credentials and contain no feed content. Disable automatic updates in the reporting page if desired. Rules and their previous revision are stored locally. A failed check keeps the last accepted pack.

The companion's local pairing token and signing private key are not distributed in this source repository. If a report accidentally exposes personal information, edit/delete it on GitHub and contact GitHub support if cached or copied content must be addressed.
